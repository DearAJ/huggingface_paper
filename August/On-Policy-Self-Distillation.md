## 背景问题（要解决什么痛点）
- On-policy（自）蒸馏（OPD / OPSD）在 LLM 后训练中潜力很大，但现有方法仍严重依赖**外部监督**：真值信号（ground truth）、环境反馈、或来自更大模型的指导，因此并非真正意义上的"自（self）"蒸馏。
- 相关的自奖励强化学习（如 RLVR/GRPO）依赖精选的真值标签，其成本与稀缺性很快成为瓶颈。
- 核心问题：能否**仅用模型自身的生成**、通过"内部一致性"实现 on-policy 自蒸馏，无需任何外部监督？

## 框架设计 / 方法
提出 **unsupervised on-policy self-distillation（u-OPSD）**。关键观察：单条 rollout 可能不可靠，但**多条独立采样 rollout 之间的一致性**提供了一个内生的置信信号，使"教师参考"与"学生轨迹"都能来自模型自身的 on-policy 采样。三步：

- **(1) Sample（采样）**：对每个无标注问题 x，按训练温度独立采样 G 条 rollout y^(1),…,y^(G) ~ π̄(·|x)（π̄ 为当前策略 π_θ 的 stop-gradient 拷贝），从 `\boxed{...}` 解析并规范化出最终答案 a^(g)=Ans(y^(g))；无法解析最终答案的（通常是截断）标记为 ∅（invalid）。
- **(2) Vote（投票）**：在有效答案中以**多数投票**得到伪答案 ã(x)=argmax_a Σ_g 1[a^(g)=a]（平票随机打破）。据此把 rollout 划分为一致集 𝒴⁺_x={y:a^(g)=ã(x)} 与不一致集 𝒴⁻_x={y:a^(g)≠ã(x)}；invalid 不属任一集。自一致性分数 c(x)=(1/G)Σ_g 1[a^(g)=ã(x)]（按总数 G 归一化，使截断降低置信度）。若 c(x)<τ，该 prompt 视为无标注、不贡献梯度。默认 **τ=1/2**（绝对多数）。
- **(3) Distill（蒸馏）**：取一条一致 rollout y⁺∈𝒴⁺_x（默认选**最长**的一致 rollout）作为教师参考，代替真值解 y*；在不一致 rollout 子集 ℬ⁻_x⊆𝒴⁻_x 的前缀上，把"以伪解为条件的教师下一词分布"蒸馏进学生。直觉：让模型恰好在"自信却错误"之处自我纠正。
- **自然课程**：自动跳过两类样本——投票不够一致者（c(x)<τ，伪答案不可靠）与全部一致者（𝒴⁻_x=∅，无可纠正的分歧）。因此训练集中在"模型能一致识别可信解、但仍对冲突轨迹分配大量概率"的能力前沿；该课程直接由模型自身投票统计涌现，无需外部难度标签。
- 与基线区别：相对 GRPO（把可验证奖励归一化为序列级 advantage）与 OPD（用更强教师的下一词分布替代稀疏标量奖励），u-OPSD 无需标注对 (x,y*)，其特权上下文完全由模型自身 on-policy rollout 构造；也不同于普通多数投票自训练——它沿不一致轨迹迁移"以解为条件的下一词分布"，提供稠密纠正监督。

## 实验结果
**设置**：四个 Qwen3 变体——Qwen3-4B、Qwen3-8B（各含 non-thinking 与 thinking 两种模式）、Qwen3-30B-A3B-Instruct-2507、Qwen3-4B-Instruct-2507；同一 checkpoint 既作学生也作教师。训练集为 OpenThoughts 的 30k 子集（u-OPSD 只用题面，不用解答字段）。基线：SFT（金解）、GRPO（金答案二元奖励）、OPSD（教师条件于金解）。评测：AIME24、AIME25、HMMT25（avg@12）与 MATH500、AMC23（avg@4）；vLLM、温度 1.0、最大生成 38k。u-OPSD 超参 G=8、τ=0.5、最大完成长度 4096。

**非思考模式（表 1，五基准平均 Avg.）**
- Qwen3-4B：Base 40.96 → u-OPSD **49.49**（+8.5%）；对比 SFT 42.73、GRPO 45.86、OPSD 46.29（u-OPSD 超 OPSD 3.2%）。
- Qwen3-8B：Base 43.57 → u-OPSD **54.31**（+10.7%）；超 OPSD（52.04）2.3%。
- u-OPSD 在两个规模上均优于所有监督基线，且在 5 个基准中有 4 个取得最佳；无标签 RL 基线在相同 rollout 预算下最多仅比 base 提升 1.5%。

**思考模式（表 2）**
- Qwen3-4B：Base 74.85 → u-OPSD **77.05**（+2.2%），领先 OPSD 0.9%、超 GRPO 0.7%。
- Qwen3-8B：Base 76.09 → u-OPSD **77.99**（+1.9%），与 OPSD（77.97）基本持平，超 GRPO 1.1%。

**指令微调模型（表 3）**
- Qwen3-30B-A3B-Instruct-2507：Base 75.77 → u-OPSD **77.46**（超 OPSD 1.1%）。
- Qwen3-4B-Instruct-2507：Base 67.00 → u-OPSD **68.78**（超 OPSD 1.7%；但在 HMMT25/MATH500/AMC23 上 OPSD 更优）。
- 表明同一配方可无特定超参调优迁移到更大的 MoE 模型。

**伪标签质量探针**：在 64 个训练 prompt、全配置（G=8、4096 token、τ=0.5）下，96.3% 的 rollout 产出可解析 boxed 答案、94.0% 的 prompt 越过自一致性阈值获伪标签、其中 86.7% 的伪标签与数据源金答案一致；少于 10% 的有效 rollout 与其投票分歧——蒸馏集小而集中。

**消融（Qwen3-8B 非思考）**
- 阈值 τ：越松越好，τ=0.3 得 58.59 > 默认 57.10 > τ=0.9 的 44.40（14.2% 跨度）。
- rollout 数 G：G=4 与 G=8 几乎无差（56.99 vs 57.10），G=12 比默认再增 4.7%（生成不受限时为更优操作点）；为与 OPSD 成本对齐而默认 G=8。
- 教师更新：默认"fixed"（冻结初始策略）；参考与蒸馏目标都偏好"最长"rollout，最佳 59.00（教师条件于最长一致、蒸馏最长不一致）；若把参考剥到只剩 boxed 伪标签，掉 10.3%–15.8%，三种 label-only 设置均低于 base 的 43.57——必须条件于较长完整推理轨迹而非仅最终答案。
- 散度：全词表 logit 蒸馏优于 sampled-token（后者比默认低 13.7%）；forward KL（β=0）最优，JSD 掉 13.8%，reverse KL 不收敛（生成逐步失去终止、字符数从 2.7k 膨胀到 99k token 上限，可解析率从 99% 跌到 33%）。top-k（top-100 附近）是降低散度计算成本的实用近似。

## 创新点
- 首次表明 on-policy 自蒸馏中的真值解可被**模型自身的多数投票共识**取代：一致 rollout 作教师参考，蒸馏只施加于自不一致 rollout——真正"无任何外部监督"。
- 关键洞见：共识作为"token 级蒸馏的条件上下文"远比作为"策略优化的标量奖励"有效（非思考模式下比自奖励 RL 平均高 7.0%–11.3%）。
- 自然涌现的课程：训练自动聚焦模型"能一致作答却仍自信犯错"的能力前沿，无需外部难度标签或调度。
- 在两个模型规模、两种推理模式、两个指令模型上验证，并对阈值、rollout 数、教师更新、散度目标做了系统消融。

## 局限与讨论
- **范围**：实验仅覆盖一个模型族（Qwen3，4B/8B 两种模式）与一个领域（可自动判定最终答案的竞赛数学）；投票机制要求可抽取、可规范化的答案，扩展到开放式生成需把精确匹配投票换成更软的共识。
- **增益随 regime 变化**：对 OPSD 的优势在非思考模式大（+3.2%、+2.3%）、思考模式小（+0.9%、≈0.02%）；对 base 的提升也从 8.5%/10.7% 收缩到 2.2%/1.9%。思考模式基线已达 74.9/76.1 且 rollout 更长，150 步预算覆盖更少完成投票。应将共识视为非思考模式下金解的"更强替代"、思考模式下的"持平"，而非一致改进。
- **受限于基模能力**：多数投票监督复现基模最常产出的答案，上界即该答案的准确率；探针测得域内 13.3% 伪标签错误，且未测试故意污染投票下的训练动态；按投票边际检测/降权低质共识是自然的后续方向。
